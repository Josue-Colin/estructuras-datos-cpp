# Cola en C++

Implementación de una cola usando nodos y memoria dinámica.

## Regla

FIFO: primero en entrar, primero en salir.

## Operaciones

- inicializar
- vacia
- enqueue
- dequeue
- peek
- mostrar
- liberar

## Complejidad

- enqueue: O(1)
- dequeue: O(1)
- peek: O(1)
- mostrar: O(n)
- liberar: O(n)

## Conceptos

Punteros, nodos, new, delete, nullptr y memoria dinámica.
