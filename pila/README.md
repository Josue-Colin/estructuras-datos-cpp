# Pila en C++

Implementación de una estructura de datos tipo pila utilizando nodos y memoria dinámica.

## Operaciones

- Inicializar pila
- Verificar si está vacía
- Push
- Pop
- Peek
- Mostrar elementos
- Liberar memoria

## Complejidad

| Operación | Complejidad |
| --------- | ----------- |
| Push      | O(1)        |
| Pop       | O(1)        |
| Peek      | O(1)        |
| Vacía     | O(1)        |
| Mostrar   | O(n)        |
| Liberar   | O(n)        |

## Conceptos utilizados

- Punteros
- Estructuras
- Memoria dinámica
- `new` y `delete`
- Listas enlazadas
- LIFO (Last In, First Out)
